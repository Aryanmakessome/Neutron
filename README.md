# Neutron

Neutron is an experimental robotic arm platform built to explore **robotics, embedded systems, wireless control, computer vision, and physical automation**.

The current platform is a compact multi-servo robotic arm controlled by an ESP32, with plans to expand its sensing and autonomous capabilities.

### Current / planned capabilities

* Multi-servo robotic arm control
* ESP32-based control system
* Wireless communication
* Gripper manipulation
* Camera-based vision
* Object detection and tracking
* Computer-controlled movement
* Autonomous task execution

### Goal

Develop Neutron from a basic robotic arm into a modular experimental platform capable of sensing its environment, making decisions, and performing physical tasks.

The project serves as a foundation for exploring larger-scale robotics and industrial automation systems.
